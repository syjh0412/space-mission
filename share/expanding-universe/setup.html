학생 기록을 내 구글 시트에 모으기

한 번만 설정하면, 우리 반 학생들이 탐구실에 입력한 예측·측정값·토의 문장·퀴즈 결과가 선생님의 구글 시트에 모이고, 선생님 화면에서 모둠별·학생별로 볼 수 있어요. 10분쯤 걸려요.

기록은 선생님 드라이브에만선생님이 만든 구글 시트에만 저장돼요. 다른 학교나 공유한 사람에게는 가지 않아요.
학생은 로그인 없이반·모둠·번호만 고르면 돼요. 이름은 받지 않아요.
모둠 공유도 함께기록 담당 한 명이 측정값을 넣으면 같은 모둠 친구 화면에도 들어가요.

  1. 새 구글 시트를 만들고 Apps Script 열기

    새 구글 시트 열기 ↗→확장 프로그램→Apps Script

    시트 이름은 아무거나 괜찮아요. 예: “우주팽창 기록 2학년”

  2. 코드를 붙여 넣고 PIN 바꾸기

    코드를 불러오는 중…

    Apps Script 편집기에 원래 있던 function myFunction() {…}을 모두 지우고 붙여 넣어요.

    맨 위의 const PIN = '0000';에서 0000을 선생님만 아는 숫자로 바꾼 뒤 저장(Ctrl+S)해요. 이 숫자가 선생님 화면 비밀번호예요.

  3. 웹 앱으로 배포하기

    배포→새 배포→⚙ 유형 선택: 웹 앱
    실행 사용자: 나액세스 권한이 있는 사용자: 모든 사용자→배포
    처음 한 번 권한 확인이 나와요. [액세스 승인] → 내 계정 선택 → “Google에서 확인하지 않은 앱” 화면이 나오면 [고급] → [(안전하지 않음)으로 이동] → [허용]. 선생님이 직접 만든 코드라서 나오는 안내예요. 이 코드는 이 시트에만 기록해요.

    배포가 끝나면 나오는 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사해요.

  4. 학생용·선생님용 링크 만들기

    학생용 링크학생들에게 이 링크나 QR을 나눠 주세요. 링크 안에 선생님 시트 주소가 들어 있어요.
    열어 보기 ↗
    화면에 띄우거나 캡처해서 수업 자료에 넣어 쓰세요.
    선생님용 링크선생님 화면이 바로 열려요. PIN을 넣으면 모둠별·학생별 기록이 보여요. 학생에게는 주지 마세요.

알아 두면 좋은 점
· 학생 기록은 시트의 우주팽창 탭에 날짜·반·모둠·번호마다 한 줄씩 쌓여요. 같은 학생이 다시 저장하면 그 줄이 갱신돼요.
· 선생님 화면에서 PIN을 넣은 기기는 교사 시범 모드가 되어, 그 기기에서 학생 화면에 입력한 것은 시트에 저장되지 않아요. 노란 띠의 [끝내기]로 끌 수 있어요.
· 나중에 코드를 고칠 때는 [배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포]로 해야 주소가 바뀌지 않아요. [새 배포]를 누르면 주소가 바뀌니 링크를 다시 만들어야 해요.
